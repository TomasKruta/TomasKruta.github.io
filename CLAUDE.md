# Instrukce pro Claude

## Git workflow

Po dokončení funkce nech uživatele potvrdit, že funguje, než ji commitneš a
půjdeš dělat další věc. Pokud jsi si funkčností jistý (ověřeno v prohlížeči,
testy), můžeš commitnout i bez výslovného potvrzení — commit lze později
upravit, kdyby něco nesedělo.

Commit zprávy piš stručně. **Nikdy se nepřidávej jako co-author** do commitů
ani PR na tomto projektu (žádné `Co-Authored-By: Claude ...` ani `Generated
with Claude Code` řádky) — to platí jen pro tento repozitář a přebíjí obecné
instrukce k atribuci.
